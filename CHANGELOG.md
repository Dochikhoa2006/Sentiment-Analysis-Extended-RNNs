# Changelog

All notable project changes are documented here.

## 2.0.0 — 2026-07-31

### Added

- Installable `src/` package and unified `sentiment-analyzer` CLI.
- Memory-bounded Keras batches for large review tensors.
- Stratified evaluation with macro-F1 and 95% confidence intervals.
- Per-fold FastText fitting to prevent evaluation leakage.
- Class-balanced training, model metadata, tests, CI, Docker packaging, and model card.
- Compatibility loading for artifacts generated by the original scripts.

### Changed

- Native `.keras` serialization replaces Joblib for new neural models.
- Unicode NFKC tokenization replaces destructive NFKD decomposition.
- Generated data and models now live in dedicated ignored directories.
- Documentation now distinguishes historical benchmarks from the current protocol.

### Fixed

- Single-review inference no longer applies `argmax` twice and always returns class zero.
- Confusion matrices use true labels on rows and predicted labels on columns.
- README fold counts and confidence levels no longer conflict with the implementation.
